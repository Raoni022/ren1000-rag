# Ideias para a v2 (não implementar agora)

Regra de escopo: qualquer ideia que aparecer durante o desenvolvimento vem para cá, não para
o escopo da v1. Nada desta lista é tocado antes da v1 estar publicada e estável.

- ~~Busca híbrida (BM25 + densa)~~ — **implementada na v1**, depois de medir: levou a
  recuperação da bateria de 6/7 para 7/7 sem piorar nenhuma pergunta. Entrou porque a falha que
  ela corrigia produzia resposta errada com citação válida, que é o defeito mais grave possível
  neste projeto.
- **Reranking com cross-encoder** sobre os candidatos da busca híbrida. É o próximo passo
  natural para a pergunta 1, em que o artigo certo é recuperado mas o modelo escolhe o trecho
  errado entre os oito — problema de seleção, não de recuperação.
- Múltiplas normas simultâneas: REN 482/2012 e 687/2015 (revogadas pela REN 1.059/2023) para
  contexto histórico, Lei 14.300/2022 completa.
- Upload de PDF pelo usuário.
- Login, histórico de conversa, persistência entre sessões.
- Interface customizada além do Gradio padrão.
- Reaproveitar o mesmo padrão para outro corpus.
- Anexos técnicos extensos da própria REN 1.000/2021.
