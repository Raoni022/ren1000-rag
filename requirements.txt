#

#     ONNX int8 ....................... 456 MB de RSS,   ~50 MB em disco

#
# Para CONSTRUIR o indice (roda uma vez, offline), use requirements-build.txt.
#
# Python 3.11. NAO usar 3.14: faiss-cpu ainda nao publica wheel para essa versao.
#
# Os limites superiores nao sao excesso de zelo: o Gradio 6 moveu `theme` do construtor do
# Blocks para o launch(), e uma faixa aberta faria o deploy instalar uma versao com API
# diferente da testada aqui.
